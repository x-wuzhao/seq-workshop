# Next v4.1 · 任务模块与验证

2026-11-01。用户批准先按任务拆分长页面。改动仅属于 `product-next`，参赛 `main`、原链接、Pages 来源保持冻结。

## 界面与共享状态

六个主模块、十五个任务视图。主导航选择任务组，二级链接选择具体工具；只显示当前视图，组成图表视图同时显示 GC 与氨基酸两个相关面板。

- 工作区保留序列编辑、概览、地图与注释。分析成功后收起编辑器。
- 顶部序列栏在各模块中显示当前序列、长度、GC，以及备份、恢复和计算记录入口。
- “更换序列”打开工作区编辑器；分析后返回此前工具。新分析清除旧引物、比对、突变和优化结果。
- 普通切换不重建工具 DOM，保留工具输入、输出和练习答案。
- 缺少已分析序列时，工具提供示例、输入与恢复入口。学习中心独立可用，示例演示明确标记数据来源。
- 路由采用 `#/group/tool`；支持前进/后退、直接链接和原有面板锚点。地图特征跳转到所属工具。
- 图表在所在视图可见时绘制，三维查看器在首次进入时初始化。离开中心法则视图停止自动播放。

## 源码职责

| 文件或目录 | 职责 |
|---|---|
| `index.html` | 页面结构与工具表单 |
| `assets/css/base.css` | 原有组件和视觉变量 |
| `assets/css/module-shell.css` | 模块布局、导航、窄屏与主题适配 |
| `assets/js/module-config.js` | 路由、分组、面板归属与序列依赖 |
| `assets/js/module-router.js` | 视图切换、共享序列上下文、缺省状态与输入返回 |
| `assets/js/modules/` | 17 个按职责拆分的现有应用源文件 |
| `assets/js/sequence-core.js` | v4 已校验的计算核心 |
| `assets/js/workspace-format.js`、`product-workspace.js` | 备份格式、恢复和计算记录 |
| `tools/build_app.js` | 按 manifest 顺序生成并核验应用运行文件 |
| `assets/js/app-bundle.js` | 已提交的生成文件；下载源码即可运行 |
| `tools/build_single_file.py` | 将本地脚本与 CSS 内联为可双击的单文件 |

现有代码包含同名函数的后续增强实现，以及依赖这些声明提升的初始化。此次保持经典脚本作用域与原始顺序，在源码层按职责拆分，生成一个运行文件；避免简单拆成多个 script 后改变初始化语义。此轮没有把旧接口全部迁移为 ES modules。后续逐个模块重构时，应先移除对应的历史覆盖和全局依赖，再迁移接口。

应用没有运行时 CDN、构建服务器或账号依赖。普通源码运行不需要先构建；修改 `modules/` 后运行 `npm run build:offline`，`npm test` 会检查生成文件是否同步。

Service Worker 缓存新增 CSS、路由和运行文件，并依据内容更新指纹。离线单文件不引用外部脚本、样式、manifest 或应用图标。

## 本轮验证

本机 Edge 独立临时配置，CDP 实际操作；截图与记录位于本地忽略目录 `artifacts/modules/`。

| 验证 | 已观察结果 |
|---|---|
| 桌面任务流程 | 21 项断言通过；输入、学习、PCR、突变、图表、3D、地图跳转、返回、旧锚点、清空 |
| 共享状态 | 切换保留序列、注释、引物与突变输出、练习答案；重新分析失效旧输出 |
| 响应式矩阵 | 360、390、768、900、1280 px，各 15 个视图，共 75 次；仅显示所属面板，无整页横向溢出 |
| 手机实际操作 | 导航菜单打开/关闭、二级工具、深色主题；有效备份恢复环状拓扑及注释，错误备份保留当前工作区 |
| 断网刷新 | localhost 上由 Service Worker 控制；新资源命中缓存，路由和样式恢复；恢复本机工作区后继续设计引物 |
| 单文件直接打开 | `file://` 下学习示例、模块切换、PCR、图表与三维初始化通过 |
| 自动回归 | 原有算法、v3 生信、v4 产品、缓存与 UI 测试，新增路由和面板归属检查 |

断网测试会触发一次预期的网络断开事件，随后应用由缓存恢复。这些结果不代表实体手机、Safari/Firefox、完整读屏体验或真实 PWA 安装已验证，也不构成生物学算法或实验可靠性的新增认证。计算模型与参考范围沿用 [v4 验证说明](VALIDATION_V4.md)。
