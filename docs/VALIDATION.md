# 序列工坊验收清单

## 功能与边界

| 场景 | 预期结果 |
|---|---|
| 空输入 | 显示“请输入 DNA 序列”，结果区保持隐藏 |
| `ATGTAA` | 能识别 ATG→终止密码子的完整 ORF，蛋白序列不出现 `undefined` |
| `TAA` | 无完整 ORF；pI、GRAVY、芳香性显示 `—`，不出现 `NaN` 或 `Infinity` |
| 含 `N` 的序列 | 反向互补保留 `N`；翻译和酶切结果给出未知位点的可理解提示 |
| RNA 输入 | `U` 自动转为 `T`，后续结果与等价 DNA 输入一致 |
| FASTA 输入 | 忽略 `>` 标题行和空白，保留序列主体 |
| 反向链最长 ORF | 密码子统计使用反向读码框的实际序列，不误用正向序列 |
| 密码子优化 | CAI 的 T/U 表示统一；同义密码子替换不改变蛋白序列 |
| 短序列图表 | 3–19 bp 序列仍显示至少一个 GC 窗口，不出现空图表 |
| 无义突变 | 提前终止密码子被分类为无义突变，不误判为错义突变 |

## v3 新增能力

| 场景 | 预期结果 |
|---|---|
| 遗传密码表切换 | 切换「脊椎动物线粒体」后，内部 TGA 翻译为 W；ORF 长度随起始密码子集合变化立即刷新 |
| 引物设计 | 给出前 5 对候选；Tm 在 50–70 °C 区间内；每对含位置、产物长度、二聚体 ΔG 与评分；首选引物给出风险提示（Tm 差、非特异、ΔG） |
| 引物边界 | 序列短于「产物长度 + 40」时提示长度不足；无候选时提示放宽参数，不出现空白结果 |
| 线状酶切 | 片段长度之和 = 序列长度；首片段左端为 `—`、末片段右端为 `—` |
| 环状酶切 | 切点数为 n 时片段数为 n；片段长度之和 = 质粒长度；单切点酶给出全长线性片段 |
| 黏性末端 | EcoRI 显示「5′ 突出 4 nt」、PstI 显示「3′ 突出 4 nt」、SmaI / ScaI 显示「平端」 |
| 双酶切 | 选两种酶时片段数 = 两种酶切点并集 + 1（线性）；凝胶出现两条泳道 |
| 局部比对 | 两条含突变的同源序列：Smith–Waterman 得分高于全局比对；一致性百分比正确 |
| 点阵图 | 同源序列出现主对角线；序列内重复片段出现平行副对角线；更换序列后重绘 |
| GenBank 导出 | 文件以 `LOCUS` 开头、`//` 结尾；`ORIGIN` 每行 60 bp；含 source / ORF / primer_bind / 酶切位点注释 |
| GenBank 互操作 | 导出文件可被 SnapGene Viewer / Benchling / UGENE 打开，ORF 和酶切位点位置与页面一致 |

## 三维结构

| 场景 | 预期结果 |
|---|---|
| 我的序列 | 分析后显示所选窗口的 B-DNA 双螺旋；5′/3′ 标注正确；中心碱基对高亮 |
| 位置联动 | 拖动滑块或点击序列碱基，模型窗口随之滚动；点击碱基对回写中心位置 |
| 显示窗口 | 18 / 24 / 30 / 36 bp 切换后重建模型，不出现空白 |
| 隐藏碱基对 | 只保留骨架，可观察大沟/小沟；再次点击恢复 |
| 结构库 | 5 个结构均可加载：1BNA、1EHZ、1L2Y（球棍）、1GFL、2HHB（卡通）；多链结构默认按链着色 |
| 结构交互 | 拖动旋转、滚轮/双指缩放、自动旋转、重置视角均正常；点击残基显示名称/链/二级结构 |
| 序列匹配 | 输入含 `CGCGAATTCGCG` 时，1BNA 卡片显示「与当前序列一致」 |
| 无 WebGL | 显示说明文字，不抛异常，其余模块不受影响；断网后结构库仍可打开 |
| 主题 | 切换深色模式后三维背景同步变化 |

## PWA 与移动端

1. 在 HTTPS 或 localhost 打开页面，检查 Manifest 和 Service Worker 均注册成功。
2. 首次联网打开并分析一次，再切换浏览器 Offline，刷新页面仍能打开核心界面、图表与结构数据。
3. 手机窄屏下，顶部导航通过菜单按钮打开，点击锚点后菜单自动关闭。
4. 窄屏下三维面板为单列；引物候选表、酶切片段表在自身容器内横向滚动，页面不出现横向滚动条。
5. 使用 Tab 键可以访问菜单、主题切换、输入框和主要操作按钮。
6. 关闭 localStorage 或使用隐私模式时，分析主流程仍能运行。
7. 开启 `prefers-reduced-motion` 时自动旋转与过渡被减弱。
8. 直接打开 `序列工坊_离线单文件版.html`，不依赖 `assets/` 目录也能完成核心分析、图表和三维结构展示。


## 界面与交互（v3.1）

| 场景 | 预期结果 |
|---|---|
| 结果概览 | 分析后顶部为一条摘要卡：长度 / GC / Tm / 分子量 + 碱基组成条；组成条各段宽度与 A/T/G/C 计数成比例 |
| 分区导航 | 结果区顶部出现吸顶小圆片；滚动到酶切、引物等分区时对应圆片高亮并自动滚入可视范围 |
| 导航顺序 | 顶部导航、分区导航、页面面板三者的顺序一致（转录→翻译→突变→三维→蛋白→酶切→引物→比对→密码子→优化→图表） |
| 窄屏 | 顶部导航收进抽屉；分区导航可横向滑动；摘要卡变为 2×2 指标 + 组成条；页面无横向滚动条 |
| 深色模式 | 提示框、突变标记、题库对错使用语义色，不出现亮色底块 |
| 反馈 | 点击「开始分析」按钮进入加载态并提示「分析完成」；导出后出现轻提示 |
| 兼容性 | 不支持 WebGL 时三维面板给出说明，其余界面与交互不受影响 |
