# 序列工坊 · 生信能力对标与 v3 升级说明

> 面向问题：如果拿「成熟的生物信息学工具」当标尺，序列工坊 v2 缺什么、这次补了什么、还差什么。
> 对标对象：SnapGene / SnapGene Viewer、Benchling、ApE（A plasmid Editor）、Geneious Prime、UGENE、Jalview、Primer3 / Primer-BLAST、NCBI BLAST、PyMOL / ChimeraX / Mol\* / NGL。
> 结论先行：v3 把「教学演示」推进到「能完成一条最小生信工作流」——**读入序列 → 找基因 → 酶切/克隆前检查 → 设计引物 → 比对 → 导出可被专业软件接续的 GenBank → 看真实三维结构**，但仍**不是**科研级平台。

---

## 一、v2 的真实短板（对标后的诊断）

把 v2 的 12 个模块逐项对照成熟工具，问题集中在四类，而不是「功能数量不够」：

1. **结果不可接续**：只能导出 CSV / FASTA。真实工作流里，下游软件（SnapGene、Benchling、UGENE）读的是 **GenBank / SBOL**；CSV 在生信里几乎是死路。这是最致命的短板——作品像一个「演示页」，而不是「工具链的一环」。
2. **算法停留在教科书简化版**：
   - 引物 Tm 用 Wallace 规则 / 64.9+41×(GC-16.4)/N，二聚体检测只是「数互补碱基个数」，没有热力学量；
   - 酶切只按线性 DNA 算，没有环状质粒、没有双酶切、没有黏性末端概念；
   - 比对只有全局比对，没有局部比对，也没有点阵图。
   这些恰恰是 Primer3、SnapGene 与教学工具的分水岭。
3. **缺少「结构」这一维**：中心法则的另一半是蛋白质三维结构。v2 只有一张 2D 投影示意图，无法回答「这个蛋白长什么样」「tRNA 为什么是 L 形」。
4. **生物学默认值不完整**：只有标准遗传密码表。线粒体基因（TGA=Trp、AGA/AGG=终止）会被整段误判为提前终止——这是一个会直接算错结果的缺陷。

## 二、v3 补上的六项能力（逐项对标）

| # | v3 能力 | 对标工具 | 实现要点 | 可验证的现象 |
|---|---|---|---|---|
| 1 | **GenBank 导出** | SnapGene / Benchling / UGENE / ApE | 生成 `LOCUS / FEATURES / ORIGIN` 标准记录；把 ORF、引物结合位点、常用酶切位点写成 `misc_feature` / `primer_bind` 注释；坐标 1-based、反向链用 `complement()`、序列小写 60 bp/行 | 导出的 `.gb` 可直接拖进 SnapGene Viewer / Benchling 打开，注释以 feature 形式显示 |
| 2 | **环状 / 双酶切 + 黏性末端 + 凝胶** | SnapGene 质粒图谱、NEBcutter | 用「切点集合 + 拓扑」计算片段：线性首尾不接、环状首尾相接；由识别序列与切点位置推导 `5′/3′ 突出` 与平端；双酶切取两种酶切点并集 | 选「环状」后片段长度之和 = 质粒长度；EcoRI 显示「5′ 突出 4 nt」、SmaI 显示「平端」；凝胶条带随酶切换 |
| 3 | **最近邻热力学 Tm + 二聚体/发夹 ΔG + 候选排序** | Primer3 / Primer-BLAST | SantaLucia 1998 的 10 组 ΔH/ΔS 与末端、对称、盐校正；ΔG37 计算自身二聚体与发夹；对候选对按 Tm 偏差、GC、3′ 端、ΔG 罚分排序，输出前 5 对并检查模板出现次数 | 20 mer 引物 Tm 落在 55–62 °C（50 mM Na⁺、0.25 µM）；表中给出每对的 ΔG 与评分；首选引物给风险提示 |
| 4 | **Smith–Waterman 局部比对 + 点阵图** | BLAST 的「局部比对方**法**」、EMBOSS water、Jalview | 在原有 Needleman–Wunsch 之外增加局部比对（得分为负即归零），输出得分/一致位点/一致性；点阵图用 k-mer 精确匹配绘制，对角线即同源片段 | 两条含 10 个突变的 203 bp 序列：一致性 95.1%、点阵图呈主对角线，重复片段出现平行副对角线 |
| 5 | **遗传密码表变体** | SnapGene / Benchling 的 translation set、NCBI 遗传密码表 | 内置标准表与脊椎动物线粒体表（TGA=W、AGA/AGG=\*、ATA=M，起始密码子含 ATT/ATC/ATA/GTG）；翻译、ORF 查找、蛋白性质、GenBank 注释全部联动 | 同一序列切到线粒体表后，ORF 由 2 aa 变 7 aa，内部 TGA 翻译为 W |
| 6 | **真三维结构（WebGL）** | PyMOL / ChimeraX / Mol\* / NGL / 3Dmol.js | 自研几何层：按 B 型标准参数生成双螺旋（10.5 bp/圈、3.38 Å/碱基对、骨架半径 9.4 Å）；解析 PDB 重原子与 HELIX/SHEET，生成卡通带（β 折叠更扁、α 螺旋更宽、无规卷曲用细管）与球棍模型；相机按包围盒 8 角点精确取景 | 结构库可切换 5 个真实结构：1BNA（DNA 双螺旋）、1EHZ（tRNA 的 L 形）、1L2Y、1GFL（β 桶）、2HHB（四聚体 + 4 个血红素）；点击残基显示名称/链/二级结构 |

### 3D 的取舍（为什么不用 3Dmol.js / NGL）

- **许可与可控性**：3Dmol.js 的代码谱系包含 GLmol 等 GPL 组件，作为参赛作品的内嵌依赖存在许可解释成本；NGL/Mol\* 体量大、按需加载复杂。Three.js 是 MIT，且「自己写分子几何」本身构成原创工作量。
- **离线承诺**：库与 PDB 坐标全部随包提供，打开结构库**不产生任何网络请求**，与「序列不上传」的隐私口径一致。
- **体积控制**：PDB 原文总量约 1.1 MB，经 `tools/pdb2json.py` 去水、去氢、只保留 CA 主链或重原子并压缩到两位小数后，5 个结构合计约 125 KB，可离线秒开。
- **诚实边界**：内置结构是 **RCSB PDB 实验坐标（CC0）**，不是本工具预测的；DNA 模型是「按标准参数生成的教学模型」，页面与文档都明确标注，不冒充实验结构。

## 四、仍然缺的能力与优先级

### P0（决定「像不像工具」，性价比最高）

1. **注释轨道（annotation track）**：SnapGene 的核心体验是把 ORF、酶切位点、引物、突变画在同一条坐标轴上，点击跳转。v3 目前各模块各自为政。实现成本：中（一个 SVG 轨道 + 统一坐标模型）。
2. **GenBank 读入**：目前只能导出。读入后即可「打开自己的质粒文件」，也能验证导出的往返一致性。实现成本：中（解析 LOCUS/FEATURES/ORIGIN，处理 complement/join 的常见子集）。
3. **多记录 FASTA + 序列集**：一次分析多条序列，批量翻译/酶切。实现成本：低。

### P1（专业度提升）

4. **引物特异性（本地近似）**：对单条模板做「唯一性 + 3′ 端错配」检查（v3 已做出现次数），真正的全基因组特异性必须联网 BLAST——建议做成**显式外链**（把引物序列带到 Primer-BLAST 页面），而不是假装本地能查。
5. **多序列比对（MSA）**：教学场景常用 Clustal 风格比对。可在 1200 bp 内实现简易渐进式比对（星形比对），并给出保守性条形图。实现成本：中高。
6. **Sanger 峰图模拟与「读序」练习**：给定序列生成带噪声的峰图，让学生判读——教学价值高、算法简单。
7. **密码子优化加约束**：目标 GC 区间、去除指定酶切位点、避免连续重复——这是基因合成公司的真实交付要求，v3 目前只按偏好替换。

### P2（明确不做或长期）

8. **BLAST 同源检索**：需要远端数据库与算力，与「零后端 / 不外传序列」的口径冲突。可以做的是「复制序列 + 一键打开 NCBI BLAST」。
9. **NGS 组装 / 变异检测 / 系统发育**：数据量与算法复杂度都超出浏览器教学工具的合理边界。
10. **分子对接、结构预测、表面静电势**：需要专门引擎；教学上可以用「内置真实结构 + 解释」替代。

## 六、怎么验证「确实变强了」

1. **算法对照**：
   - 用同一段序列在 Primer3 与序列工坊分别设计引物，比较 Tm（允许 ±1.5 °C，差异主要来自盐条件与 Mg²⁺）；
   - 用 EcoRI + BamHI 双酶切一个已知质粒，片段长度应与 SnapGene / NEBcutter 一致（环状时片段数 = 切点数）；
   - 两条同源序列分别跑全局/局部比对，局部比对得分应接近 EMBOSS `water` 的结果。
2. **格式往返**：导出 GenBank → 用 SnapGene Viewer / Benchling 打开 → 检查 LOCUS 长度、ORF 坐标、酶切位点是否落在预期位置。
3. **边界**：含 `N`、长度 3 bp、长度 50 kb、全 A/T 序列、只有反向链 ORF 的序列，均不应出现 `NaN` / `Infinity` / 白屏。
4. **三维**：切换 5 个结构不报错；旋转/缩放/点击残基正常；无 WebGL 时给出说明而不是崩溃；断网后仍可打开结构库。

## 七、一句话总结

v2 是「把中心法则讲清楚」的教具；v3 在保留教学叙事的前提下，补上了**可接续的导出、热力学引物、环状酶切、局部比对与真三维结构**，让它第一次能嵌进真实的生信工作流。真正的科研级能力（BLAST、测序、MSA、结构预测）仍然明确缺席——这在作品说明里应当如实写清楚，而不是用功能数量掩盖。
