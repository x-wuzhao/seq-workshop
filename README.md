# 序列工坊 Next · 本地 DNA 工作台

**本分支是参赛提交后的独立产品迭代。比赛网页、main 和 Pages 配置保持冻结。**

- 产品源码：[product-next](https://github.com/x-wuzhao/seq-workshop/tree/product-next)
- 冻结的比赛网页：[原参赛地址](https://x-wuzhao.github.io/seq-workshop/)
- 冻结基线：`57e9a4f2ba14234026f9417019038509c6f6c3de`
- 本分支不向 Pages 发布。请勿合并到 main，或切换原 Pages 的发布来源。

Next 的目标是一个**序列留在本机、工作区可恢复、计算过程可复核**的轻量工作台。支持 DNA / 质粒地图、注释、酶切与虚拟凝胶、引物候选、全局/局部比对、GenBank 及工作区导出；同时保留中心法则和三维教学模块。当前产品版本 4.1.0，计算核心沿用 v4 已校验模型。

## 任务模块

当前界面按任务切换，共享一份序列工作区。切换模块保留注释、工具输入和已计算结果；输入新序列并重新分析后，旧的衍生结果失效。

| 模块 | 内容 | 本地入口 |
|---|---|---|
| 工作区 | 序列输入、概览、地图与注释 | `#/workspace` |
| 序列分析 | 互补与转录、六框翻译、蛋白性质、密码子、组成图表 | `#/sequence/transcription` |
| 实验设计 | 限制性酶切、PCR 引物 | `#/design/digest` |
| 序列比对 | 全局/局部比对与点阵图 | `#/compare` |
| 结构与突变 | 突变模拟与三维模型 | `#/explore/mutation` |
| 学习中心 | 中心法则、知识练习、概念速查 | `#/learn/dogma` |

学习中心无需载入序列；中心法则演示明确标记所用的内置示例。分析工具缺少序列时，提供示例、输入和恢复入口。支持浏览器前进/后退，以及原有 `#nav-primer` 等锚点。

源码职责、兼容性取舍和本轮验证见 [模块结构说明](docs/MODULES_V41.md)。

## 运行

下载 product-next 分支后，在源码目录运行：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 `http://localhost:8000`。无需 npm 安装、账号或后端；运行库和 PDB 索引均随源码提供。首次访问并完成缓存后，可离线刷新。PWA 安装需要 HTTPS 或 localhost，实际安装体验取决于浏览器和设备。

直接打开 index.html 可使用核心功能，file 协议不支持 Service Worker。也可生成无外部脚本的单文件：

```sh
npm run build:offline
```

输出 `序列工坊_离线单文件版.html`。该生成文件不重复提交到 Git，由 CI 构建并提供下载 artifact。

## 三条核心流程

1. **分析与核对**：载入 390bp 教学示例 → 序列地图 → 突变选择 +1、第 87 位、替换 A → 查看 TAT→TAA 无义突变，以及同一原始 ORF 的 28aa 截短产物。
2. **保存与接续**：输入/导入序列 → 添加注释或设置环状视图 → 备份工作区 → 在另一设备恢复 JSON。备份验证通过后才替换当前数据；衍生结果重新计算，不复用过期引物和突变结果。
3. **结果复核**：点击“导出计算记录” → 获得原始序列、注释、遗传密码表、组成统计、六框 ORF 摘要、引物候选、模型参数与来源链接。记录包含原始序列，应保存在可信位置。

引物示例：390bp 教学序列，长度20bp、目标55°C、产物300bp，可产生带风险提示的候选。给定参数找不到候选是正常结果，不代表一定存在符合要求的引物。

## v4 改进

| 范围 | 行为 |
|---|---|
| 输入 | 单记录 FASTA 严格解析；多条记录明确拒绝，保持坐标；分析与比对采用相同规则 |
| 未知碱基 | N 保留；GC/AT/N 按总长度分别计算；不输出含 N 的确定 Tm、分子量或偏好评分 |
| 转录演示 | 相同片段的模板链按3′→5′逐位配对，与独立书写的反向互补序列区分 |
| 突变 | 可选六个读码框；沿原 ORF 起点比较；区分同义、错义、无义、起始改变、终止丢失、移码及无法判定 |
| 状态 | 重新分析使旧工具结果失效；修改输入后隐藏旧结果；恢复不加载过期计算 |
| Tm | 修正 SantaLucia 1998 参数和自互补处理，与独立参考值校验 |
| 密码子 | 按当前遗传密码表做同义替换；实际改变计数；简化指标明确命名为偏好排名分数 |
| 接续 | 有版本与边界检查的工作区备份/恢复，独立计算记录导出 |
| 离线与移动 | 内容指纹缓存版本、按应用作用域隔离缓存、抽屉导航、表格局部滚动、弹窗焦点约束 |
| 导入 | 注释文本转义；复杂 GenBank 位置明确提示跳过数量 |

## 验证

```sh
npm run build:offline
npm test
```

Node 22+，单文件构建使用 Python 3，无 npm 第三方开发依赖。

- 128 个标准/脊椎动物线粒体密码子与 Biopython 1.86 参考结果一致。
- 14 组 Tm，含自互补与不同长度，在同样参数下误差小于0.01°C。
- 回归覆盖 N、多 FASTA、正反链突变、起始/终止改变、过期结果、备份校验和注释转义。
- 浏览器实测示例、突变、引物、备份及计算记录下载、320/390/768px 重排、断网刷新与工作区恢复。

参考 fixture 由独立工具生成；日常测试不依赖 Biopython，也不联网。[详细验证范围](docs/VALIDATION_V4.md)。这些测试不能证明全部算法和实验场景正确。

## 适用范围

- 单条序列最长50,000bp；比对每条最长1,200bp。长序列完整 UI 性能仍需专项测试。
- 面向学习和初步分析。引物未模拟 Mg²⁺、dNTP、聚合酶体系；ΔG、二聚体与发夹筛选为近似值，需要专业工具及实验复核。
- 偏好表是内置排名示例，未经表达体系频率校准；排名分数不是标准 CAI，不承诺表达量提升。
- 标准表的 ORF 仅按 ATG 寻找；线粒体按列出的起始密码子处理，不等同于完整基因预测。
- GenBank 支持连续区间、单个位点及 complement；join、order、模糊边界等复杂位置会跳过并提示。
- 三维为理想 B-DNA 几何模型或随包真实 PDB 结构，不提供结构预测。
- 原创价值、真实使用效果及国赛竞争力仍需用户研究、对照使用和团队贡献证据；本分支不保证任何奖项。
