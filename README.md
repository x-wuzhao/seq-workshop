# 序列工坊 · 中心法则交互式工作台

> 一个纯前端、零后端的分子生物学交互式教学工具。
> 粘贴一段 DNA 序列，即可在同一次操作中看到它反向互补、转录为 mRNA、按六个读码框翻译成蛋白质，并获得蛋白质理化性质、限制性酶切位点、双序列全局比对、密码子使用频率与 GC 含量可视化结果。

**参赛作品** — 2026 年第十四届全国大学生数字媒体科技作品及创意竞赛 · 自主选题类（二）移动与网络应用开发类

## 三、功能模块

| # | 模块 | 说明 |
|---|---|---|
| 1 | 输入区 | 支持直接粘贴与 FASTA 格式（自动忽略 `>` 开头的说明行）；提供示例序列一键加载 |
| 2 | 反向互补与转录 | 互补链、反向互补链、mRNA（编码链 T→U） |
| 3 | 六框翻译与开放阅读框 | 正反链各三个读码框的翻译结果与 ORF 识别 |
| 4 | 蛋白质理化性质 | 分子量、理论等电点、GRAVY 亲水性（参照 ExPASy ProtParam；疏水性用 Kyte–Doolittle 标度） |
| 5 | 限制性酶切位点分析 | 32 种常用限制酶的识别位点与切割位置（同时扫描互补链） |
| 6 | 虚拟凝胶电泳 | 按酶切片段大小模拟电泳条带 |
| 7 | 双序列全局比对 | Needleman–Wunsch 全局比对，匹配／错配／空位分值可调 |
| 8 | 密码子使用频率 | 64 个密码子的使用次数与频率 |
| 9 | 可视化与教学区 | GC 含量沿序列分布曲线、氨基酸组成柱状图；五组教学问答 |

## 四、隐私与数据安全

**所有计算均在你的浏览器本地完成，序列不会被上传。**

| 措施 | 实现 |
|---|---|
| 无网络请求 | 源码中 `fetch` / `XMLHttpRequest` / `WebSocket` 出现次数均为 0 |
| 无后端服务 | 不需要服务器、数据库或接口 |
| 不采集用户信息 | 无账号体系、无表单提交、无 Cookie、无跟踪代码 |
| 序列不留存 | 序列不写入 `localStorage`，刷新即清空（仅主题偏好被记忆） |

---

## 五、使用限制（如实说明）

1. 双序列比对的序列长度上限为 **1200 bp**，超出时页面会给出提示（这是为保证浏览器端渲染流畅而设的护栏）；
2. 限制性内切酶检测范围为本工具收录的 **32 种**常用酶，非全酶库；
3. 蛋白质理化性质为理论计算值，与实验测定值可能存在差异；
4. 本工具定位为**教学演示**，不作为科研级分析依据。

## 六、技术说明

| 项 | 内容 |
|---|---|
| 架构 | 纯前端单页应用（SPA），零后端 |
| 技术栈 | HTML5 + CSS3 + 原生 JavaScript（ES5 语法） |
| 框架依赖 | **无**（未使用 jQuery / Vue / React 等任何框架） |
| 第三方库 | 仅 ECharts 5.5.1（Apache-2.0），用于两处图表 |
| 核心算法 | 均由本项目自行实现：`reverseComplement`、`transcribe`、`translateFrame`、`findORFs`、`gcWindows`、`scanEnzyme` / `analyzeEnzymes` / `enzymeFragments`、`nwAlign`（Needleman–Wunsch）、`calcTm`、`calcMW`、`protCharge` / `calcPI` / `calcProtProps` |
| 浏览器兼容 | Chrome / Edge / Firefox / Safari 及移动端浏览器 |
| 素材依赖 | 无任何第三方图片、音频、视频素材；图标为自绘内联 SVG |
